# المرحلة الثانية: الأداء وCore Web Vitals

**الحالة:** مكتملة مختبرياً. القياسات أدناه اختبارات Lighthouse محلية على نسخة الإنتاج المبنية لمسار GitHub Pages، وليست بيانات ميدانية من زوار الموقع.

## ما تغيّر

استُضيفت خطوط Tajawal محلياً بصيغة WOFF2، في مجموعتي Arabic وLatin للأوزان 400 و500 و700 و800. ثُبّتت نسخة Fontsource المستخدمة في سكربت التوريد، وحُفظ ترخيص SIL Open Font License 1.1 في `public/fonts/OFL.txt`. صار Vite يصدر الخطوط بأسماء fingerprinted وروابط تتبع `base` تلقائياً؛ وتأكد البناء من سلامة الملفات الثمانية. يُعرض وزن 600 بأقرب وجه متاح، 700. مصدر الخطوط والترخيص موضحان في [مراجع الأداء](performance-sources.md).

تُنشأ نسخ WebP وAVIF بعرضي 480 و1200 بكسل من الرسم الأصلي للمشروع، ويعرضها `<picture>` باستخدام `srcset` و`sizes` وأبعاد محددة، مع تحميل كسول للصورة أسفل الصفحة. لا تستخدم الصفحة صوراً تجارية جاهزة.

الصفحات العامة تصل كـ HTML عربي مسبق التوليد، مع CSS نقدي صغير مضمّن وورقة الأنماط المحلية قبل الرسم الأول. أبقينا ورقة الأنماط render-blocking بدلاً من تأخيرها؛ فقد كشف القياس أن التأخير يسبب CLS كبيراً رغم تحسّن المظهر بعد التحميل. النسخة النهائية سجّلت CLS صفراً. لا تحمّل هذه الصفحات حزمة React أو Supabase؛ أما صفحات الدخول والملف الخاص والخلاصة ولوحة التحكم فتُحمّل ديناميكياً. أصبح عميل Supabase في chunk منفصل لا يُطلب من الصفحات العامة.

أضيفت أيضاً تحسينات تباين للنصوص والعناوين المتسلسلة، وضُبطت روابط الخطوط والأصول لتعمل مع قاعدة GitHub Pages الحالية أو نطاق مخصص بتغيير `VITE_SITE_URL` فقط. اجتاز البناء فحص القاعدة الحالية `/mojtama-al-saytara/` ونطاقاً مخصصاً على الجذر `https://example.com/`.

## Lighthouse المختبري

شُغّلت Lighthouse 12.8.2 في Chromium headless على HTML النهائي، مع استضافة محلية للنسخة المبنية على المسار نفسه. في نسخة الاختبار فقط تغيّر origin إلى localhost كي تُحمّل الأصول والسكربتات من النسخة المحلية؛ لم تتغير ملفات الإنتاج لهذا الغرض.

| الصفحة | الأداء | إمكانية الوصول | أفضل الممارسات | SEO | FCP | LCP | CLS | TBT |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| الرئيسية `/` | 99 | 100 | 100 | 100 | 1.5 ثانية | 1.7 ثانية | 0 | 0 مللي ثانية |
| عن المجتمع `/about/` | 97 | 100 | 100 | 100 | 1.5 ثانية | 1.9 ثانية | 0 | 0 مللي ثانية |

وصلت الفئات الأربع إلى 95 أو أكثر في الصفحتين المقاسَتين. هذه **نتائج مختبرية لعينة صفحتين**؛ لا تضمن نتيجة مماثلة على كل جهاز أو شبكة، ولا تُعد بديلاً عن بيانات CrUX/المستخدمين الفعلية. لم يُقَس بعد مسار لوحة الأعضاء الخاصة أو طلبات Supabase الحية.

## التحقق القابل لإعادة التنفيذ

- `npm run fonts:vendor` يعيد جلب الحزمة المثبّتة، ونسخ الأوزان والمجموعات المطلوبة، وتحديث CSS والترخيص.
- `npm run images:optimize` يعيد إنشاء WebP/AVIF من الرسم الأصلي (يتطلب FFmpeg).
- `npm run build` يشغّل TypeScript وVite وHTML prerender ومدقق SEO والأصول والخطوط.
- `npm run test:seo-fixtures` يبني بيانات عربية اصطناعية للمقالات والفعاليات والكوتشات ويتحقق من HTML وJSON-LD وsitemap. لا يتصل الاختبار بقاعدة الإنتاج.
- `npm run lint` و`npm run typecheck` يجريان فحوص الكود.

**حدود التحقق:** Lighthouse أعلاه جرى على نسخة ثابتة محلية قبل النشر؛ ليس قياساً لمزود Supabase أو OAuth أو قواعد البيانات. يلزم إعادة فحص URL المنشور بعد اكتمال GitHub Actions، ومتابعة تقارير Core Web Vitals الميدانية بعد وصول زيارات كافية.
